# KATA UDE UKE — Manual Ilustrado de Ju-Jitsu (14 Movimentos)

Aplicação web com a reconstrução visual padronizada das ilustrações dos **14 movimentos do Kata Ude Uke** (Série de Defesas com o Antebraço).

## Movimentos Ilustrados (1 a 14)

1. **AGE-UKE** — Defesa ascendente alta (Jodan) — movimentos 1 e 2
2. **GEDAN BARAI UKE** — Defesa descendente varrendo (Gedan) — movimentos 3 e 4
3. **SOTO-UDE-UKE** — Defesa média de fora para dentro (Chudan) — movimentos 5 e 6
4. **UCHI-UDE-UKE** — Defesa média de dentro para fora (Chudan) — movimentos 7 e 8
5. **MAE-UDE-UKE** — Defesa frontal direta na linha central — movimentos 9 e 10
6. **MAWASHI-UDE-UKE** — Defesa circular envolvente — movimentos 11 e 12
7. **JUJI-UDE-UKE GEDAN / JODAN** — Defesas em cruz baixa e alta — movimentos 13 e 14

## Como Executar Localmente

```bash
npm install
npm run dev -- -p 43123
```

Abra a app no browser e use o botão **Imprimir / Guardar PDF** (ou `Ctrl/Cmd + P`) para imprimir o manual ou guardá-lo como PDF.
